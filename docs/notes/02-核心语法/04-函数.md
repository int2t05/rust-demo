# Functions(函数)

一句话:函数用 fn 定义,参数和返回值必须显式标注;函数体是语句和表达式的序列,最后一句表达式就是返回值。

## 它解决什么问题

函数是组织代码的基本单位。Rust 的签名强制写清「进来什么、出去什么」,类型不对编译不过,调用点在编译期就被检查。

真正的特色在函数体内部:Rust 严格区分「做事不产值」的语句和「求值」的表达式——省掉 return 的仪式感,也让块、if 这些结构天然可以当值用。参数传进去之后原变量还在不在,则由类型决定。

## 核心规则

- 块 `{}` 也是表达式:最后一行无分号就是块的值——后面 if/loop/match 能当值用,靠的是同一套机制。
- 提前退出的错误分支用 return,正常出口用末尾表达式,两种出口在同一个函数里并存很常见。

## 示例

摘自 `06-functions/src/main.rs`:

```rust
fn add(a: i32, b: i32) -> i32 {
    // 最后一个表达式（无分号）作为返回值
    a + b  // 注意：没有分号！这是表达式，不是语句
}

fn abs(x: i32) -> i32 {
    if x < 0 {
        return -x;  // 提前 return，需要分号
    }
    x  // 末尾表达式作为返回值
}

fn greet(name: &str) {
    println!("你好，{}!", name);
}

fn expression_demo() -> i32 {
    // 语句：let 是语句，不返回值
    let x = 5;  // 语句

    // 块表达式：{} 可以作为表达式
    let y = {
        let z = x * 2;
        z + 1  // 块的最后一个表达式（无分号）作为块的值
    };  // y = 11

    y  // 函数的返回表达式
}

fn double(n: i32) -> i32 {
    n * 2
}

fn print_string(s: String) {
    println!("传入的字符串: {}", s);
}
// ...(略)

let num = 42;
let doubled = double(num);
// Copy 类型：num 传入后仍可用
println!("原 num 仍可用: {}", num);

let text = String::from("Hello");
print_string(text);
// println!("text: {}", text);  // 错误：value borrowed here after move

let text2 = String::from("World");
print_string(text2.clone());  // clone 传副本
println!("text2 仍可用: {}", text2);
```

## 源码解读

crate:`06-functions/src/main.rs`,`cargo run -p functions_demo` 可运行。

| 小节 | 演示什么 | 关键行 |
|---|---|---|
| add | 末尾无分号表达式作返回值 | `a + b`(无分号) |
| abs | 提前 return 与末尾表达式并存 | `return -x` |
| greet / do_nothing | 无返回值标注,隐式返回 () | `fn do_nothing() -> ()` |
| expression_demo | 块表达式求值,结果 11 | `let y = { ... z + 1 }` |
| double | Copy 类型传参,原变量仍可用 | `println!("原 num 仍可用: {}", num)` |
| print_string | 非 Copy 类型 move,传后失效;clone 可保留原变量 | `print_string(text)`、`text2.clone()` |

## 避坑

- 末尾多写一个分号,返回值就从 `i32` 变成 `()`,报 `expected i32, found ()`——十有八九是分号。
- `let x = (let y = 5);` 编译不过:let 是语句,不产生值;想先算一块逻辑,用块表达式。
- 参数传 String 这类非 Copy 类型会 move,调用后原变量失效;还要用就传 `&` 或 clone(深入见 03-所有权系统)。
