# Iterators(迭代器)

一句话:迭代器把「遍历、转换、汇总」拆成惰性可组合的小块,最后一次消费才执行,编译后与手写循环性能相同。

## 它解决什么问题

手写 for 循环把「怎么取元素」「怎么过滤」「怎么汇总」混在一起,想复用其中一步只能整段复制。迭代器把每一步做成独立的小方法:适配器(map/filter)负责转换,消费器(sum/collect)负责触发与产出,按需拼装。

迭代器是惰性的:适配器只记录「要做什么」,不调用消费器就一个元素都不处理——这也是编译器能把整条链优化成单层循环的前提。

## 核心规则

所有迭代器都是 `Iterator` trait 的实现,只需定义 `next`(返回 `Option<Item>`,`None` 表示结束);map、filter、sum 等几十个方法都是它的默认方法。执行时机:

```mermaid
flowchart LR
  A["数据源(集合或区间)"] --> B["适配器:map / filter / take<br/>返回新迭代器,不处理元素"]
  B --> C["消费器:sum / collect / find<br/>逐个调用 next,触发执行"]
  C --> D["最终结果"]
```

- 三种获取方式:`iter()` 借用元素、`iter_mut()` 可变借用、`into_iter()` 消耗集合取得所有权;`for x in &v` 等价 `v.iter()`。
- 适配器返回新迭代器,可无限串联;消费器消耗迭代器,一条链只能有一个终点。
- 零成本抽象:编译器把迭代器链内联展开为与手写循环等价的代码,没有额外运行时开销。

## 示例

摘自 `25-iterators/src/main.rs`:

```rust
// iter():借用元素,原 vec 仍可用
let v = vec![10, 20, 30];
for x in v.iter() {
    print!("{} ", x);
}

// into_iter():消耗 vec,取得所有权
let v2 = vec![10, 20, 30];
for x in v2.into_iter() {
    print!("{} ", x);
}

// iter_mut():可变借用,可修改元素
let mut v3 = vec![10, 20, 30];
for x in v3.iter_mut() {
    *x *= 2;
}

// 适配器:惰性不执行,collect 触发
let mapped: Vec<i32> = v.iter().map(|x| x * x).collect();
let evens: Vec<&i32> = v.iter().filter(|x| *x % 2 == 0).collect();

// ...(take/skip/enumerate/zip/flat_map 与消费器演示省略,见源码)

// 链式调用:适配器串联,消费器收尾,无中间集合
let result: i32 = (1..=10)
    .filter(|x| x % 2 == 0)   // 2,4,6,8,10
    .map(|x| x * x)           // 4,16,36,64,100
    .sum();                    // 220

// ...(Fibonacci/RangeStep 结构体定义省略,见源码)
// 实现 Iterator trait 只需定义 next 方法
// 迭代器是惰性的:不调用消费器就不会真正执行
impl Iterator for Fibonacci {
    type Item = u64;

    fn next(&mut self) -> Option<Self::Item> {
        let next_val = self.prev + self.curr;
        self.prev = self.curr;
        self.curr = next_val;
        Some(self.prev) // 返回当前项
    }
}

// 无限序列靠消费器截断
let fibs: Vec<u64> = Fibonacci::new().take(10).collect();
```

## 源码解读

crate:`25-iterators/src/main.rs`,`cargo run -p iterators_demo` 可运行。

| 小节 | 演示什么 | 关键行 |
|---|---|---|
| 1 三种迭代方式 | iter 借用、into_iter 消耗、iter_mut 可变借用 | `v.iter()`、`v2.into_iter()`、`v3.iter_mut()` |
| 2 适配器 | map/filter/take/skip/enumerate/zip/flat_map,惰性不执行 | `.map(\|x\| x * x)`、`.zip(ages.iter())` |
| 3 消费器 | sum/count/collect/any/all/find/max/min,触发执行 | `v.iter().sum::<i32>()`、`v.iter().find(...)` |
| 4 链式调用 | 区间直接迭代;split_whitespace 统计词数与字符 | `(1..=10).filter(...).map(...).sum()` |
| 5 自定义迭代器 | Fibonacci 无限序列靠 take 截断;RangeStep 到 end 停 | `impl Iterator for Fibonacci`、`RangeStep { current: 0, end: 20, step: 3 }` |
| 6 零成本抽象 | 迭代器链编译期展开为等价循环,无运行时开销 | `v.iter().filter(...).map(...).sum()` |

## 避坑

- 适配器惰性:只写 `v.iter().map(...)` 不接消费器,什么都不执行,还会触发「未使用结果」警告;链尾必须接消费器或交给 for。
- 别过早 collect:每次 collect 都生成中间 Vec;保持整条链惰性,最后一次 collect。
- `iter()` 产出的是引用:闭包里写 `*x` 解引用,或用模式 `|&x|` 直接拆包;要拿到所有权值用 `into_iter()` 或先 `copied()`。
